# Imported design docs from Max Krol's fork

Everything in this directory was written by [Max Krol](https://github.com/m8j8k)
in his fork, [Madison's Sand](https://github.com/m8j8k/madisons-sand-game),
and is preserved **verbatim** as the design and plan record for the features
merged back into Rainbow Sand from that fork: iPad standalone/fullscreen,
pink water, gumdrops, palm trees, flamingos, poodles, multi-touch strokes,
sounds, on-device saving, photo sharing, and grass-grown flowers.

These documents use the fork's name, "Madison's Sand", and describe the game
from the fork's point of view — that is their historical context and they are
deliberately not rewritten. The live product documents are the top-level
README, [`.specify/memory/constitution.md`](../../.specify/memory/constitution.md),
and `specs/`; those say Rainbow Sand.

Future changes to these features go through the Wing Commander pipeline like
any other feature (issue → spec → plan → tasks → implement → PR); the specs
that come out of that live in `specs/`, not here.
